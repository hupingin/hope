# Hope UI Engine 需求清单

> 项目：**Hope（希望）** — 从零自研的类浏览器 UI / 渲染引擎
> 目标：遵循 W3C 规范（HTML / CSS / DOM / JS 子集），纯 C11、零第三方库，仅解析本地文件，不做联网
> 约定：`[x]` = 已完成；`[ ] **待完成**` = 未完成
> 最后更新：2026-11-27（§14 新增「与 Chromium（Blink）对齐缺口清单」——经 OpenGrok 对比 chromium-120.0.6099.298 整理）

---

## 0. 项目基线 / 硬约束

- [x] 纯 C11，不使用 C++，无第三方依赖
- [x] CMake + MinGW GCC 构建（同时兼容 MSVC）
- [x] 抽象平台层：系统能力只能经 `hpe_platform.h` 访问
- [x] 自研软件光栅，像素级自己合成，不依赖 Direct2D / Skia
- [x] 像素格式 32bpp `0xAARRGGBB`、自上而下，与 Win32 `StretchDIBits` 零转换互通
- [x] 内存统一走 `hpe_alloc / hpe_calloc / hpe_free`
- [x] 模块依赖单向（hope → html → dom → css → layout → paint → render → platform），禁止反向
- [x] 无网络能力（不做远程资源加载、不做 JS 网络 API）
- [x] 写代码同时补齐设计文档（`docs/design.md` + `AGENTS.md`）
- [x] 遵守 `docs/AI代码生成规范.md`：全项目无函数超过 50 行（`python3 docs/func_len_audit.py 50` 为空）
