Hope — 希望

A pure-C UI engine that parses local HTML + CSS and renders it with its own software rasterizer.

Pipeline

Every frame walks the same stages as a browser engine: parse → style → layout → paint → composite.

  • HTML tokenizer and tree builder
  • CSS selector matching with cascade and inheritance
  • Block layout with inline text flow and word wrapping
  • Antialiased text composited by an 8-bit coverage rasterizer

Inline 滴滴滴formatting

Mixed runs keep their own colors and weights: bold text, red accent, and plain text all flow inside one paragraph. 中文换行也在这里测试：引擎对中日韩字符按单字断行，对拉丁文本按单词断行，这样可以避免长单词提前折行导致的排版空隙。
